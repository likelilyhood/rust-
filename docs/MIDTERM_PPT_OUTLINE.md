# logscope 中期实验答辩 PPT 大纲

## 1. 封面
- 项目名称：logscope 多格式日志分析与动态可视化平台
- 课程名称 / 实验名称
- 小组成员
- 指导教师

## 2. 研究背景与问题提出
- 系统运行日志体量大，人工排查效率低
- 不同来源日志格式差异大，难以统一分析
- 传统实验项目往往只有静态展示，缺少动态演示与故障复盘能力

## 3. 项目目标
- 支持多种日志格式的统一解析
- 提供实时统计、异常识别和动态可视化
- 支持在线导入、演示模式、分析报告导出
- 为课程答辩、实验展示和后续落地预留扩展空间

## 4. 总体架构
- 日志输入层：文件导入 / 在线导入 / TCP 输入 / HTTP 实时入口
- 解析层：JSON / Access Log / Lambda / Elasticsearch 自动识别
- 统计层：吞吐、错误率、分位数、热门路径、滚动窗口
- 展示层：健康评分、服务热力榜、异常明细、事件回放、对比分析

## 5. 核心功能
- 多格式日志兼容与合法化
- 健康评分与告警面板
- 动态演示模式
- 异常明细与根因候选洞察
- 服务热力榜与关键事件回放
- 报告导出与历史快照

## 6. 关键技术实现
- Rust 并发处理与异步队列
- 统一事件模型 LogEvent
- 滚动窗口聚合与延迟分位数统计
- 前端按需渲染、低重绘更新
- 导入模式与实时模式的语义区分

## 7. 当前阶段成果展示
- 展示健康评分、状态分布、热门路径
- 展示导入分析摘要与异常样本
- 展示服务热力榜与事件回放
- 展示基准对比和历史快照

## 8. 动态演示流程
- 阶段一：正常流量
- 阶段二：错误突增
- 阶段三：延迟升高
- 阶段四：恢复阶段
- 讲解重点：指标波动、异常聚焦、路径变化、服务受影响程度

## 9. 实验效果与价值
- 提高日志分析的可读性与演示性
- 支持从统计概览下钻到异常请求
- 为课程展示、比赛答辩和企业实训提供统一展示入口

## 10. 当前不足
- 智能洞察目前以规则分析为主
- 历史数据持久化能力仍较轻量
- 外部告警订阅和权限系统尚未完全落地
- 实时接入方式仍可继续扩展

## 11. 未来使用方向
- 教学实验平台：日志分析、异常检测、系统观测课程展示
- 比赛作品平台：创新大赛、计算机设计大赛、服务外包大赛
- 轻量运维工具：中小团队内部日志观测与故障复盘
- 安全日志平台：结合审计日志、攻击流量和异常行为识别
- 云原生场景：微服务接口质量监控、性能回归分析

## 12. 后续规划
- 增加更多行业模板：电商、校园、云服务、安全审计
- 引入更强的根因候选分析与异常评分模型
- 支持 WebSocket / 目录监听等更多实时输入方式
- 完善角色视图、告警订阅、历史检索与部署方案

## 13. 总结
- 已完成的阶段成果
- 当前项目亮点
- 下一阶段优化目标

## 14. 答辩讲解建议
- 先讲痛点，再讲架构，再现场演示
- 演示时优先播放“错误突增”与“延迟升高”两个阶段
- 最后用未来方向收束，体现项目可持续演进能力
