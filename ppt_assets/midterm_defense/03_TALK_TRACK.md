# 答辩讲稿提要

## 开场

各位老师好，我们的项目是 `logscope` 多格式日志分析与动态可视化平台。我们希望解决的问题是：日志很多，但传统日志展示方式难以快速反映系统状态，也不利于课程答辩和实验展示。

## 项目目标

我们的目标有三点：

1. 统一接收和解析多种日志
2. 维护关键运行指标
3. 通过可视化界面把日志变化和异常过程展示出来

## 架构介绍

整体流程是：

日志输入 -> 结构化解析 -> 聚合统计 -> 前端展示

在实现上，我们使用 Rust workspace 划分成 `common`、`parser`、`aggregator`、`server` 和 `generator` 五个模块。

## 功能亮点

### 多格式兼容

支持 JSON、Access、Lambda 结构化日志和 Elasticsearch 服务日志。

### 并发 pipeline

原始日志进入有界队列，多 worker 并发解析，最后由聚合模块统一统计。

### 动态展示

前端不只是静态面板，还支持：

- 演示模式
- 异常明细
- 智能洞察
- 服务热力榜
- 事件回放
- 基准对比
- 历史快照

## 演示时重点讲法

### 第一阶段：正常流量
- 看健康评分高
- 错误率低
- 吞吐平稳

### 第二阶段：错误突增
- 看错误率上升
- 看 5xx 路径集中
- 看异常明细和服务热力榜

### 第三阶段：延迟升高
- 看 P95/P99 抬升
- 看事件回放里慢请求增加

### 第四阶段：恢复阶段
- 看指标回落
- 看对比分析和历史快照

## 总结讲法

这个项目已经不仅是一个日志统计工具，而是一个适合实验答辩、教学展示和后续扩展的轻量日志观测平台。
