# 项目摘要

## 项目名称

logscope 多格式日志分析与动态可视化平台

## 一句话介绍

这是一个使用 Rust 构建的实时日志分析平台，支持多格式日志接入、异常统计、动态演示和答辩展示。

## 项目背景

传统日志往往以原始文本形式存在，难以快速反映系统整体健康状况。面对不同来源、不同格式的日志，人工排查效率低、展示效果弱，也不利于实验答辩和项目讲解。

## 项目目标

1. 支持多种日志格式统一解析
2. 支持实时统计与异常识别
3. 提供适合答辩展示的前端可视化界面
4. 支持在线导入、动态演示和报告导出
5. 为后续结题答辩、比赛和轻量落地留出扩展空间

## 当前核心能力

- JSON / Access / Lambda / Elasticsearch 日志兼容
- 在线导入与实时流式输入
- 健康评分、状态分布、路径排行、滚动窗口
- 分位数统计：P50 / P95 / P99
- 告警展示与异常样本提取
- 动态演示模式
- 智能洞察、服务热力榜、事件回放
- 对比分析、历史快照、报告导出

## 技术亮点

### 1. Rust 并发架构

- 多 worker 解析
- 单聚合任务维护状态
- 支持有界队列与背压/丢弃策略

### 2. 多格式日志统一建模

所有日志最终都会映射为统一 `LogEvent`，方便后续统计、异常识别和可视化。

### 3. 动态答辩友好

项目不是单纯做接口，而是围绕“如何演示”和“如何讲清楚问题”设计了大量可视化和交互逻辑。

## 当前项目价值

- 可作为课程设计/实验答辩项目
- 可作为日志分析教学案例
- 可作为轻量日志观测系统原型
- 可作为比赛作品继续扩展
