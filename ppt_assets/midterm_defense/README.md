# logscope 中期答辩素材包

这个目录用于集中存放 `logscope` 项目中期答辩所需的素材，方便直接交给外部开源 PPT 制作工具使用。

## 固定素材库约定

从现在开始，这个目录被视为本项目的**固定答辩素材库**，同时承担以下职责：

- 作为中期答辩的统一素材来源
- 作为后续结题答辩的统一素材来源
- 作为比赛展示材料的基础素材来源
- 作为后续项目演进时需要优先维护的答辩知识库

也就是说，后续如果项目继续增加功能、优化演示或扩展应用场景，**优先更新这个目录，而不是零散地重新写一套答辩材料**。

## 默认维护规则

后续每次项目迭代时，都默认遵循下面这条规则：

> 任何会影响“项目定位、核心功能、演示流程、未来方向、答辩讲法”的改动，都要同步更新这个素材库。

如果没有特别说明，后续答辩相关内容都以这个目录为准。

## 目录说明

- `00_MATERIALS_INDEX.md`：素材总索引，适合先读
- `01_PROJECT_BRIEF.md`：项目概述与亮点摘要
- `02_MIDTERM_PPT_OUTLINE.md`：中期答辩 PPT 大纲
- `03_TALK_TRACK.md`：答辩讲稿与口播思路
- `04_DEMO_SCRIPT.md`：现场演示流程与讲解顺序
- `05_DATASET_RECOMMENDATIONS.md`：推荐演示数据集与使用建议
- `06_FUTURE_ROADMAP.md`：后续演进方向与结题答辩可继续强调的点
- `07_UPDATE_CHECKLIST.md`：每次版本迭代后建议更新的内容
- `manifest.json`：给自动化工具读取的结构化素材索引

## 建议用法

1. 先把整个目录交给 PPT 生成工具
2. 让工具优先读取：
   - `00_MATERIALS_INDEX.md`
   - `01_PROJECT_BRIEF.md`
   - `02_MIDTERM_PPT_OUTLINE.md`
3. 如果需要生成讲稿，再补充：
   - `03_TALK_TRACK.md`
   - `04_DEMO_SCRIPT.md`
4. 如果需要补充未来方向和落地叙事，再加入：
   - `05_DATASET_RECOMMENDATIONS.md`
   - `06_FUTURE_ROADMAP.md`

## 后续维护原则

- 中期答辩使用这个目录
- 结题答辩继续沿用这个目录，在原有文件基础上迭代
- 后续所有答辩材料默认从这个目录生成
- 每次项目功能增加后，优先更新：
  - `01_PROJECT_BRIEF.md`
  - `04_DEMO_SCRIPT.md`
  - `06_FUTURE_ROADMAP.md`
  - `07_UPDATE_CHECKLIST.md`
